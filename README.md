# Last Text at One Percent

make.fun bounty entry for **"Last Text at One Percent"** — a dying-phone
final text message, 1–200 characters.

Bounty: https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876

## Entry

> If this is the last text I get to send tonight, let it be this:
> I love you, I'm safe, and I'll call the moment I'm home.

## How it works

`main.py` (Python 3, standard library only) writes the entry text to
`/output/entry.txt` with world-readable permissions (mode 644) and
validates that the text is a single line of 1–200 characters.

Run it with:

```sh
python3 main.py
```
